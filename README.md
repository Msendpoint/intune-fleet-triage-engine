# Intune Enterprise Fleet Triage & Sync Engine

> An enterprise-grade modern endpoint diagnostics and synchronization framework designed to bridge the gap between OMA-DM and IME execution states.

## Overview

This PowerShell project was extracted from an article on [MSEndpoint.com](https://msendpoint.com) and is part of the professional automation portfolio.

### Quick Start

```powershell
# Clone the repository
git clone https://github.com/Msendpoint/intune-fleet-triage-engine.git
cd intune-fleet-triage-engine

# One-click install & run (checks prerequisites, installs modules, launches main script)
.\Install.ps1
```

PowerShell, Microsoft Graph, PHP

## Requirements

- PowerShell 7.0 or later
- Microsoft Graph CLI (if applicable)
- Appropriate administrative permissions
